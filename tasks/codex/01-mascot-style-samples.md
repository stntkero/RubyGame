# Codex Task 01 — Mascot style samples (images only)

You are generating concept art for an original children's mobile game (player is a 3-year-old).
**Do not create or modify any code files.** Only produce images.

## Character: 露比 (Ruby) the kitten — ORIGINAL character
- A small, round, chibi-proportioned **pink kitten** (head about half of total height), soft pastel pink fur with a lighter cream-pink belly, muzzle and inner ears
- Big friendly dark eyes with white highlights, tiny pink nose, small happy open-mouth smile, short whiskers
- A thin red collar with **one ruby-red heart-shaped gem** pendant (faceted, shiny)
- A **small rounded backpack** in mint/teal worn on the back, with a little white heart on its flap (no text, no logos, no badges, no shields)
- Short curled tail
- Must NOT resemble any existing franchise character (no PAW Patrol, Hello Kitty, Pusheen, Marie, etc.): no uniforms, no helmets, no shield badges, no dogs

## Pose (identical in both images)
Full body, standing, facing the viewer, slight 3/4 turn, right paw raised in a cheerful wave, centered, with generous empty margin around the character. Plain, flat, solid **pure white background** (#FFFFFF), no ground shadow, no scenery, no text, no watermark. Square 1024×1024.

## Two styles — generate exactly 2 images
- **A — Picture-book watercolor**: soft watercolor washes, gentle paper grain, soft colored-pencil outlines, warm and cozy like a premium toddler picture book
- **B — Flat cute vector**: clean flat shapes, bold thick dark-navy outline (#2F3A68), minimal soft cel shading, bright saturated pastel palette, sticker-like, very readable at small sizes on a phone

## Output
- Save to the workspace as:
  - `assets/samples/01-mascot-A-watercolor.png`
  - `assets/samples/01-mascot-B-flat.png`
- Create the `assets/samples/` folder if needed. Copy the generated image files there (don't just leave them in the default generated-images location).
- When done, print the two saved file paths and one sentence describing each image. Nothing else.
